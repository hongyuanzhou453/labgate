# 研究管理目录规则（LabGate 开源版）

本目录汇总 LabGate 默认闭门（Fail-Closed）科研治理系统所需的规范契约、标准库工具、合成示范卷宗与六套隔离验收测试。

## 结构与职责

- `README.md`：中文系统操作说明、CLI 日常入口与阶段门禁边界。
- `建设路线.md`：W1–W13 共用能力建设状态与后续确认性准入依赖说明。
- `来源映射.json` & `来源登记.json`：声明式上游研究资料与审计视图映射，核对路径、字节数、SHA-256 与表头。
- `规范/`：已实现的契约规范、词表与阶段要求（`G1` / `G2` / `G3`）。
- `工具/`：纯 Python 3.12 标准库实现，所有入口含 `main` 守卫与 `--dry-run`，无 import 副作用。
- `测试/`：针对状态一致性、文献联查、协议冻结、并发、破坏性篡改、路径边界与周报承接的正负例验证。
- `看板/` & `派生/看板/`：复用内置 `vendor/rtr-ui-kit` 的只读离线看板生成器与静态单文件 HTML 输出。
- `问题/<problem_id>/`：独立课题卷宗（状态、假设、预算与协议草稿；未确认字段严格保持 `null`）。
- `周报记录/` & `派生/周报/`：ISO 周规范源 JSON 与承接式周报派生视图（受 `.reports.lock` 保护，禁止手工覆盖）。
- `_交付/demo-baseline/`：本仓库自带合成示例基线与通过验收的运行报告。

## 核心纪律

- 所有检查器均遵循 **Fail-Closed**：缺前置科研决定、缺外置确认原件、缺合规快照或存在未授权运行包敏感值时显式退出拒绝，绝不静默降级或代填决定。
- 使用 `python3 -B` 运行全部 CLI，所有 `--dry-run` 只读校验不创建文件或锁。
