# v0.2.1 首轮实施范围

依据Downloads中保留的规划v0.2、执行规格v0.2及用户后续建设授权。本页记录已实现接口及尚未实现部分，不更改旧版本。Python 3.12，仅标准库；不涉及HTML/PDF渲染。本轮实测Python 3.12.2，完整版本以验收报告为准。

## 已实现

- 来源：登记22个现有文件的路径、SHA-256、表头、权威职责与核验范围；台账通过workspace_paths.resolve解析。输入变化要求新版本登记，重跑同输入不覆盖旧捕获时间。
- 运行：完整UUID4，revision从0连续递增，父字节哈希关联；科学身份从首版固定。running无终止/失败字段，failed与interrupted有原因；中断还需明确证据。终态只许带依据的备注纠错。进度/资源/产物提交前校验全部文件引用。
- 预检：递归验证实际文件及manifest引用，绑定协议、数据、划分、配置与运行身份；记录实际Python。此版本支持smoke及exploratory元数据链路，confirmatory启动明确拒绝。没有认证真实GPU环境或训练可复现性。
- 同步：输入目录与存储互不包含；本地POSIX flock串行化，prepared→持久文件→committed→派生索引/日志。相同版本同hash无操作、异hash拒绝、缺父拒绝、旧版不回退。事务为权威，索引及同步日志均可从事务重建。失败命令输出结构化诊断；调用方保留失败输出，本轮保存在commands.json。
- 恢复：prepared仅缺文件时要求原包重送；文件已齐则复核后提交；committed后的索引丢失可重建。检查点必须有本地字节引用，续跑使用新ID并指向已提交的中断/失败父运行及其登记检查点。
- 资格：用途视图沿用既有测量ID；diagnostic允许留档，point_training只给pending或exclude。工具拒绝把未核/插补/界限/其他端点提升为精确Kd点。无正式训练include。

## 相对执行规格的具体收敛

本轮采用更严格的终态元数据纠错，只开放备注/依据，不支持产物位置迁移。artifacts在本地目录包内使用`kind,path,sha256,bytes,availability`；远程URI、签名URL、云存储适配不在本轮实现。同步日志从已提交事务原子重建，具有transaction_id唯一性；它不作为独立事实追加源。prepared与失败尝试保留在事务和命令诊断中。正式环境配置和结果准入不能由这一简化实现推定通过。

运行原生字段由run_contract.py验证；JSON拒绝重复键及NaN/Infinity，所有文件引用必须有相对路径和完整SHA-256。数值0有效，unknown不是0。env不适用字段为null且带missing_reasons；科学身份、环境、配置改变须新开运行。

## 阶段检查的实际含义

G1检查状态九节、保护输入哈希、来源清单/映射、比较表和关系端点回台账以及工具语法。来源接入并未重审文献结论或关系可比性。G2要求当前工具内容哈希、全部固定正负例及其留存文件通过；是本机POSIX合成链路验收。G3 prepare检查真实诊断视图后，明确失败于未决研究选择及未实现的科学检查。G3 result始终拒绝，直到另轮实现和验收；改配置开关不能放行。

未实现项：正式冻结/测试访问登记、真实数据集与角色划分及联合桥接独立验算、真实GPU预检、基线/对照复现与适配验收、预算实耗、统计分析和正式结果准入。W7/W10b/W12/W13仍未完成。工程身份校验不是防恶意管理员篡改的签名体系。

## Opus反馈的处理

附件标题称38条，实际提供S01–S09，其余未读到，不能登记“全部38条已接受”。

| 条目 | 处理 |
| --- | --- |
| S01 | 接受状态/失败字段问题；采用不可变revision而非run_id+status，允许多次running进度 |
| S02 | 校验器前置；阶段外检查明确列出，阶段内缺项失败，不用跳过伪装通过 |
| S03 | 云端独立发号；使用完整UUID4，不截为8位 |
| S04 | 新机器ID允许ASCII大小写、数字、点和连字符；旧证据/比较ID原样保留 |
| S05 | 工具和合成链路不等真实协议；实际训练依赖G3，草稿与冻结分开 |
| S06 | 新增路径按实施计划及目录规则限定；本轮单一整合者，不启动多agent并行改写 |
| S07 | 快照采用内容hash；本轮明确62项保护范围，未宣称全盘hash审计；git status不能代替内容证据 |
| S08 | 复用已有规范化及映射，不另建一套standardize.py |
| S09 | 检查必需单元格非空，不禁止自然语言空格 |

首批真实闭环后评估字段使用成本；历史revision、冻结输入和验收证据不因未触发错误而删除。
